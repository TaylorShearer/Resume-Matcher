## 2025-05-18 - Explicit Accessible Name and Description Wiring for Composite Switch Components
**Learning:** In compound switch components where the visual `<label>` wraps both the primary label and supporting description text, standard `htmlFor` association can cause screen readers and accessibility trees to lump the helper description into the accessible name of the switch (e.g. name becomes "Strict ModeEnforces ATS parsing validation."). Splitting the accessible name explicitly via `aria-labelledby` pointing to the title label and wiring the description via `aria-describedby` gives screen reader users clean, distinct announcements for the control's name and its supplementary hint.
**Action:** Always decouple title from description in compound Swiss form rows by binding `aria-labelledby` to the primary label text and `aria-describedby` to the description container.
